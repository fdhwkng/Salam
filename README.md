# Nexcent Landing Page

Responsive, single-file Nexcent-inspired website.

## Run locally
Open `index.html` in a browser. All styling, layout and menu interactions are included in this file.

## Deploy
- **Netlify:** import this GitHub repository and leave the build command blank; set publish directory to `.`.
- **Vercel:** import the repository as an Other/static project without a build command.
- **GitHub Pages:** open Settings → Pages, select Deploy from a branch, `main` and `/ (root)`.

## Notes
The HTML currently contains inline SVG illustrations and stylized placeholders, rather than the source PNG assets. It is deployable but is not an exact reproduction of the supplied screenshots. The newsletter form is illustrative and does not send emails.
